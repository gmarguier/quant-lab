# Quant Lab

Plateforme de révision pour les entretiens de quant research : cours complet (19 chapitres),
422 questions avec réponses exactes vérifiées, chrono et suivi de progression.

**Ouvrir :** https://gmarguier.github.io/quant-lab/

**Sur téléphone :** ouvre le lien puis
- iPhone (Safari) : Partager → « Sur l'écran d'accueil » ;
- Android (Chrome) : menu ⋮ → « Installer l'application ».

L'app fonctionne ensuite hors ligne. La progression est stockée sur l'appareil ; pour la
transférer d'un appareil à l'autre : Progression → Exporter, puis Importer sur l'autre appareil.

Ce dépôt ne contient que la version construite (`index.html` autonome, manifeste, service worker,
icônes). Elle est générée par `node tools/build.mjs --pwa site` depuis les sources locales.
